# グンギ（軍議）

『HUNTER×HUNTER』の盤上遊戯グンギを、ブラウザ対局できるファン再構成アプリです。

- **Web**: 静的ビルドをそのままホスティング（Vercel など）
- **ローカル**: `npm run dev` または `npm run build && npm run preview`
- **ルール**: アプリ内「ルール」タブで駒の動き・山・配置手順を説明

原作では完全な競技ルールが未公開のため、ガイドブック断片と作中描写に基づくプレイアブル版です（非公式）。

## 使い方

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開く。対戦モードから選べます。

- **ローカル2人** — 同じ端末で交互操作
- **対CPU** — 先手（あなた）vs 後手（CPU）／時間表示なし
- **オンライン** — 部屋コード対戦／参考の整数秒のみ

対局ログは裏で `logs/telemetry.jsonl` に適度に残ります（解析画面なし）。あとからチャットで解析依頼できます。

本番向け:

```bash
npm run build
npm run preview
```

`dist/` を任意の静的サーバへ置けば Web 公開できます。

## 対局の流れ

1. 配置フェーズで自陣（先手は下3段／後手は上3段）に手駒を置く
2. 帥を置いたら「配置完了」（両者完了で対局開始）
3. 手番ごとに駒移動または手駒打ち
4. 相手の帥を取った側の勝ち
